# Drinking-Water Quality Analysis

A data analytics project that evaluates 30 simulated water samples from five different water sources using Python, SQL, and Microsoft Excel.

## Project Overview
This project analyzes six water-quality parameters: pH, TDS, Total Hardness, Chloride, Nitrate, and Fluoride.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- SQLite
- Microsoft Excel
- ReportLab

## Key Results
- Total samples: 30
- Water sources: 5
- Samples passed: 22
- Samples failed: 8
- TDS recorded the highest number of failures.

## Project Features
- Water-quality data analysis
- SQL database management
- Statistical calculations
- Data visualization
- Excel reporting
- PDF report generation

## Dataset Disclaimer
All sample data is simulated for educational purposes. It does not represent actual laboratory measurements.

## How to Run

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

Run the analysis script using the appropriate filename:

```bash
python water_quality_analysis.py
```
